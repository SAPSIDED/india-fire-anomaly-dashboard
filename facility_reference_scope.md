# Facility Reference Scope: CPCB Review

The proposed CPCB Red/Orange/Green/White source was reviewed before ingestion. The government-hosted search result describes a numbered list of **industry sector types**, while the official/publicly indexed category material does not provide a national facility register with a facility name and address for each classified entity. It is therefore a sector taxonomy, not a geocodable list of individual facilities.

The user selected the safe alternative: typed OpenStreetMap facility context together with the existing WRI Global Power Plant Database reference. No CPCB row, location, or category is ingested, and no geocoding runs. This prevents unverified facility locations from being created from a non-geographic source.

1. [CPCB category-list search result on the Forest Clearance portal](https://forestsclearance.nic.in/DownloadPdfFile.aspx?FileName)
2. [Maharashtra Pollution Control Board: Revised Categorisation of Industries](https://www.mpcb.gov.in/en/consentmgt/revised-industry-categorization)
